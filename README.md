# Wispr Me backend template

Deploy this backend to your own Cloudflare account. Set GROQ_API_KEY to your own Groq key and DEVICE_TOKENS_JSON to the connections generated by the offline Setup.html supplied with your apps. No seller credentials are used.

[Deploy to Cloudflare](https://deploy.workers.cloudflare.com/?url=https%3A%2F%2Fgithub.com%2Fjenul942%2Fwispr-me-deploy)
